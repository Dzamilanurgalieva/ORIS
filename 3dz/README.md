# Многопоточный сервер задач

Клиент-серверный todo-лист по TCP. Сервер держит один общий список задач, к нему подключается сколько угодно клиентов, все видят один список

## Запуск

Сервер:
python server.py

Клиенты (в отдельных терминалах):
python client.py

## Команды

- `/add <текст>` — добавить задачу
- `/list` — показать все задачи
- `/done <номер>` — отметить выполненной
- `/delete <номер>` — удалить задачу
- `/quit` — выйти

## Потоки

После `accept()` сервер создаёт отдельный поток `handle_client` на каждого клиента. Главный поток сразу возвращается к `accept()` и принимает новых. Так несколько клиентов работают одновременно, а не по очереди

## Синхронизация

Список `tasks` общий, к нему лезут все потоки. Доступ защищён `tasks_lock`:

- сборка списка для `/list`;
- добавление в `/add`;
- проверка и изменение в `/done`;
- проверка и удаление в `/delete`.

`send_message` вызывается вне лока и если нет то медленный клиент заблокирует остальных

## Ошибки

Обрабатывается:
- несуществующий номер (`/done 99`);
- нечисловой номер (`/done abc`);
- пустой `/add`;
- неизвестная команда;
- `ConnectionResetError`, `BrokenPipeError` — при обрыве связи
