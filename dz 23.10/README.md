# Task Manager 2.0 (PyQt6)

Домашка по ОРИС. Улучшенная версия менеджера задач на Python с PyQt6.

## Реализованные пункты: B, D, F + Бонус (JSON)

*   **B. Удаление с подтверждением:** Кнопка *Delete selected* удаляет задачу из списка. Перед удалением появляется окно `QMessageBox` с запросом подтверждения.
*   **D. Диалог настроек:** Кнопка *Settings* открывает `QDialog` с чекбоксом. При нажатии OK включается тёмная тема через `setStyleSheet`.
*   **F. Пользовательский сигнал:** В главном окне создан `pyqtSignal(str)`. При успешном создании задачи сигнал испускается и меняет текст статуса внизу окна.
*   **Бонус. Сохранение в JSON и редактирование:**
    *   Задачи хранятся в файле `tasks.json` и загружаются при старте.
    *   Любое изменение (создание, удаление, правка) обновляет файл.
    *   При клике на задачу в списке она загружается в форму для редактирования. Кнопка *Create task* меняется на *Save changes*.
